# Design

## Context

全新專案。主體是一個排版視窗；負擔最小的路徑是「拖入 → （必要時）拉一下滑桿 → 按完成」。See proposal.md for motivation。

## Goals / Non-Goals

**Goals:**
- 零設定即可完成：預設類型、預設字幕列高度皆可直接用。
- 排序、類型規則、裁切與拼接放在純邏輯 library，可單元測試。

**Non-Goals:**
- 自由畫布、逐張裁切、圖片編輯。

## Decisions

1. **Swift + AppKit/SwiftUI 選單列 App（`LSUIElement`，`NSStatusItem`）；點圖示開／關排版視窗**
   接近 Shottr 的常駐低負擔使用感。替代方案：Tauri/Electron（較肥）、Python 腳本（不像 App）。

2. **SwiftPM，拆為 `StitchCore`（純邏輯）與 `SubtitleClipper`（App）；腳本包成 `.app`**
   不依賴 Xcode 專案檔，利於 CLI 建置與 TDD。`StitchCore` 只依賴 CoreGraphics。

3. **清單模型：`ComposeItem { image, kind: frame | subtitle }` 的有序平面清單；幕由清單推導**
   每個 `frame` 開新一幕，其後連續的 `subtitle` 屬於該幕，跨幕移動即改變位置，不需巢狀結構。

4. **不變量：第一項必為 `frame`**
   切換或拖曳若會讓第一項成為 subtitle 則拒絕；移除第一項時新的第一項自動轉為 `frame`。此規則置於 `StitchCore` 並以測試覆蓋。

5. **字幕列範圍：單一全域的 `CropBand { top, bottom }`（皆為圖片高度比例，0–1，預設 0.85–1.0，高度下限 0.02），在畫面圖上以紅框顯示並可拖曳上下緣**
   一個長截圖統一範圍；用「上緣＋下緣」才能同時調整大小與位置（有些字幕下方留白很多）。以比例儲存使不同解析度也能套用，寬度固定全寬。值存 `UserDefaults`。紅框畫在畫面項目的縮圖上（SwiftUI overlay，拖曳把手在上下緣），所有畫面項目皆顯示同一個紅框，在任一張上拖曳都同步；拖曳座標以圖片實際顯示尺寸換算，縮放檢視時不會錯位。替代方案：滑桿（無法調位置，已淘汰）。

6. **清單即預覽（WYSIWYG）**
   純字幕項目以裁切後樣貌顯示，紅框移動時即時更新。清單背景為黑色，與輸出底色一致。

7. **匯入**：Finder 拖入（多檔依檔名自然排序）、`NSOpenPanel` 多選、`Cmd+V` 讀剪貼簿圖片（追加到末端）。非圖片檔忽略。

8. **垂直拖曳排序改用自訂手勢重排（`ScrollView` + `LazyVStack` + `DragGesture`），不使用 `List.onMove`**
   系統 `onMove` 無法自訂落點指示與邊緣自動捲動。自訂版本顯示跟隨游標的半透明預覽、插入線、並在游標靠近可視區上下緣時以計時器捲動（越近越快）。「游標位置 → 插入索引」「邊緣捲動速度」「落點合法性（第一項限制）」寫成 `StitchCore` 內的純函式並以單元測試覆蓋；UI 只負責手勢與繪製。替代方案：保留 `onMove`（無法客製，已被使用者回報不夠好用）。
9. **拼接與輸出**：寬度以第一張為基準，其他等比縮放至同寬；所有項目（含幕與幕之間）無縫堆疊，無間隔；整張畫布先填黑色；之後依「輸出解析度倍率」（25/50/75/100%，預設 100%，存 `UserDefaults`）縮放整張結果（高品質插值，四捨五入至少 1 px）再編碼 PNG 至剪貼簿；存檔預設關閉，啟用後存同一份 PNG 到指定資料夾。完成後清單保留，另有「清空」。倍率不影響預覽。

10. **縮圖降採樣顯示，輸出時才載入原圖**，避免大量大圖佔用記憶體。縮放檢視放大時縮圖解析度需足夠（降採樣上限提高到可支援 4× 放大的合理值）。

11. **縮放檢視**：清單內容套用 `scaleEffect`／佈局縮放（觸控板 `MagnifyGesture`、`Cmd+=`/`Cmd+-`/`Cmd+0`），範圍 25%–400%，只影響顯示；視窗右下顯示目前比例。

## Risks / Trade-offs

- [單一字幕列範圍不適合所有截圖（字幕位置或行數變動）] → v1 接受；紅框可隨時調整，後續可加逐張覆寫。
- [截圖寬度不一致] → 等比縮放至第一張寬度；於說明中註明。
- [縮放檢視下紅框拖曳座標易錯位] → 座標一律以圖片實際顯示框換算成比例，並以邏輯函式（比例↔座標）單元測試。
- [黑底與無縫拼接使幕與幕難以分辨] → 以預覽中的幕標示（僅視窗內，不進輸出）輔助辨識。
- [DRM 內容截圖本身可能為黑畫面] → 非本工具範圍。
