# Proposal

## Why

目前整張長圖只有一組字幕紅框。實際影片中，不同畫面的字幕位置可能不同（例如畫面 1 的字幕在下緣，畫面 2 的字幕被移到較高的位置），單一紅框無法同時涵蓋，使用者只能放大範圍並輸出多餘內容。

## What Changes

- 字幕紅框改為「每一幕」各自可有一組；某一幕的字幕圖使用該幕畫面圖上的紅框。
- 預設不覆寫：新的一幕沿用前一幕實際生效的紅框，沒有調整時行為與現在完全相同（單一紅框套用全部）。
- 使用者在某一幕的畫面圖上拖曳紅框，即為該幕建立專屬範圍；該幕之後尚未自訂的幕會跟著變動，已自訂的幕不受影響。
- 畫面／字幕切換、移除、拖曳排序時，紅框覆寫跟著各幕的畫面項目走：畫面轉為字幕則覆寫捨棄；字幕轉為畫面則沿用前一幕。
- 輸出、預覽與標記疊圖都改用各幕實際生效的紅框。
- 記住上次值：最近一次調整的紅框範圍，成為下次啟動時第一幕的預設。
- 不新增「重設為沿用」按鈕（見 design 非目標）。

## Capabilities

### New Capabilities

（無）

### Modified Capabilities

- `drag-compose`: 「統一字幕列範圍（紅框）」改為每幕可獨立的字幕列範圍。

## Impact

- `Sources/StitchCore`：`ComposeItem` 增加可選紅框覆寫、`ComposeList` 計算各項目生效紅框並在切換類型時維護覆寫、`Stitcher` 逐項使用生效紅框。
- `Sources/SubtitleClipper`：`AppModel`、`ComposeView`、`AnnotationPreview`／`AnnotationLayer` 的紅框讀寫與預覽高度計算。
- 測試：`ComposeListTests`、`StitchTests`、`SettingsTests`。
- README 的紅框說明與「已知限制」第一項需更新。
- 標記座標以長圖寬度正規化、不隨內容移動的既有限制不變；每幕紅框高度不同會改變長圖高度，使既有標記位置相對內容偏移，與調整紅框的既有行為一致。
