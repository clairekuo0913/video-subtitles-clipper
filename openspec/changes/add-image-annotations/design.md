# Design

## Context

排版視窗已是黑底無縫的長圖預覽，輸出由 `Stitcher` 以 CoreGraphics 產生。標記疊加在這個長圖之上，故可視為「畫布覆蓋層」。See proposal.md for motivation。

## Goals / Non-Goals

**Goals:**
- 預覽即結果：預覽與輸出使用同一個繪製器，避免文字排版或馬賽克結果不一致。
- 標記資料與 UI 分離，核心可單元測試。

**Non-Goals:**
- 標記隨圖片移動、重做、圖層管理、可再編輯的專案檔。

## Decisions

1. **座標以長圖寬度正規化（x、y、寬、高皆除以長圖寬度）**
   與縮放檢視、輸出倍率、不同截圖解析度無關；長圖高度變動時標記保持原座標不動。替代方案：以像素（隨倍率錯位）、以高度比例（高度變動時漂移）。

2. **標記模型：`Annotation { id, kind, rect/points, style }`，kind 為 text / rectangle / arrow / mosaic**
   清單 `AnnotationList` 負責新增、更新、刪除、z 順序（新建者在最上）與撤銷堆疊，全部放在 `StitchCore`，只依賴 CoreGraphics。限制：建立與移動時夾限於長圖範圍內。

3. **繪製器 `AnnotationRenderer`（CoreGraphics + CoreText，位於 `StitchCore`）**
   輸入拼接後的長圖、標記清單與輸出倍率；繪製順序：先對底圖做所有馬賽克，再依 z 順序繪製其他標記。馬賽克以區域縮小再最近鄰放大實作（純 CoreGraphics，結果可預期、可測試）。文字以 CoreText 在文字框矩形內換行繪製。
   預覽的非編輯中標記也由此繪製器輸出一層透明圖覆蓋，確保與輸出一致；編輯中的標記以 SwiftUI 顯示選取框與把手。

4. **標記模式與排版模式互斥（工具列切換）**
   標記模式下停用項目拖曳排序、紅框把手與類型徽章的點擊；縮放檢視保留。以此避免與標記手勢衝突。

5. **建立流程：選工具 → 在長圖上拖曳出範圍；文字框建立後直接進入文字輸入**
   「選取」工具可選取、移動、以把手縮放、Delete 刪除；Cmd+Z 撤銷最近一次標記操作（新增、移動、縮放、修改樣式、刪除）。

6. **樣式**：文字框有文字顏色、底色（含無）、字體大小（相對長圖寬度）、粗體、邊框；矩形與箭頭有顏色與粗細；馬賽克無樣式（僅區塊大小固定比例）。新建標記沿用上次選用的樣式（`UserDefaults`）。

7. **輸出整合**：`Stitcher.stitch` 增加標記參數，先拼接，再繪製標記，最後套用輸出倍率（標記座標已正規化，故隨倍率一致）。

## Risks / Trade-offs

- [重新排序或調整紅框後標記不跟著內容走，可能蓋到錯誤位置] → 已列為範圍外；標記完成後再排版需使用者自行調整。切到標記模式時於提示中說明。
- [CoreText 與預覽字型在不同字型下行為差異] → 預覽與輸出共用同一繪製器，僅使用系統預設字型。
- [長圖很高時覆蓋層圖片佔用記憶體] → 覆蓋層以目前縮放與可視範圍繪製，或限制最大尺寸；任務中以大長圖驗證。
- [馬賽克不可逆但非加密] → 說明於 README，不宣稱安全遮蔽。
