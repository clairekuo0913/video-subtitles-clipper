# Spec Delta

## ADDED Requirements

### Requirement: 輸出包含標記
完成輸出（剪貼簿與存檔）時，系統 SHALL 將所有標記繪製在拼接後的長圖上，結果 MUST 與視窗內預覽一致；馬賽克 SHALL 先套用於底圖，其餘標記依建立順序由下而上繪製；輸出解析度倍率 SHALL 同時套用於標記，使標記與長圖維持相同相對位置。沒有標記時輸出 MUST 與既有行為相同。

#### Scenario: 標記進入輸出
- **WHEN** 長圖上有文字框與箭頭，使用者按「完成」
- **THEN** 剪貼簿 PNG 中包含這些標記，位置與預覽一致

#### Scenario: 馬賽克遮蔽輸出
- **WHEN** 長圖上有馬賽克標記，使用者按「完成」
- **THEN** 輸出圖中該區域為馬賽克，原內容不可辨識

#### Scenario: 圖片標記輸出
- **WHEN** 長圖上有貼上的圖片標記，使用者按「完成」
- **THEN** 輸出圖中該圖片位於與預覽一致的位置與大小

#### Scenario: 倍率與標記
- **WHEN** 輸出倍率為 50%，長圖上有標記
- **THEN** 輸出圖尺寸為一半，標記相對於長圖的位置與大小比例不變

#### Scenario: 無標記
- **WHEN** 長圖上沒有任何標記
- **THEN** 輸出與沒有標記功能時完全相同
