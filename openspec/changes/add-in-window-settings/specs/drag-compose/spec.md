# Spec Delta

## ADDED Requirements

### Requirement: 設定可在視窗內操作
排版視窗 SHALL 提供「設定」選單，包含：同時存檔到資料夾（開關）、選擇存檔資料夾、浮在所有視窗之上（開關）、快捷鍵狀態，以及離開；其效果 MUST 與選單列右鍵選單中的同名項目一致，且兩處的狀態 SHALL 即時同步。快捷鍵註冊失敗時，設定選單 SHALL 顯示警示。

#### Scenario: 在視窗內開關存檔
- **WHEN** 使用者在視窗的設定選單勾選「同時存檔到資料夾」
- **THEN** 選單列右鍵選單中該項目也顯示為勾選，之後完成輸出會另存檔案

#### Scenario: 在視窗內切換浮動
- **WHEN** 使用者在視窗的設定選單取消「浮在所有視窗之上」
- **THEN** 視窗立即變為一般視窗，選單列右鍵選單的該項目也顯示未勾選

#### Scenario: 選單列被隱藏時仍可設定
- **WHEN** 其他 App 處於全螢幕、選單列隱藏，使用者在排版視窗內開啟設定選單
- **THEN** 使用者可完成上述所有設定操作

#### Scenario: 快捷鍵衝突提示
- **WHEN** 預設快捷鍵註冊失敗
- **THEN** 視窗的設定選單顯示快捷鍵不可用的警示

#### Scenario: 從視窗離開
- **WHEN** 使用者在視窗的設定選單選擇「離開」
- **THEN** App 結束
