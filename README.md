# 字幕拼接（Subtitle Clipper）

把多張影片截圖整理成一張長圖：每一幕第一張是完整畫面，其後只保留字幕列，垂直緊接堆疊、黑色底。
macOS 選單列 App，純離線，不連網。

## 需求

- macOS 14 以上
- Xcode（或 Swift 6 toolchain）

## 建置與啟動

```bash
bash scripts/build-app.sh
open build/SubtitleClipper.app
```

App 只有選單列圖示（無 Dock 圖示），啟動時會直接開啟視窗。
首次開啟若被 macOS 擋下（未簽署），請在 Finder 對 `build/SubtitleClipper.app` 按右鍵 → 打開。

執行測試：

```bash
swift test
```

## 操作

1. **開關視窗**：點選單列圖示，或按全域快捷鍵 `⌃⌥Space`（在任何 App、包含全螢幕畫面都可用）。視窗預設是浮動面板，會停在其他視窗之上，可在全螢幕畫面上直接拖動；若覺得礙事，在選單列圖示按右鍵（或視窗工具列的齒輪設定）取消「浮在所有視窗之上」，視窗就會變成一般視窗。
2. **匯入截圖**：從 Finder 拖進視窗、按「匯入…」多選，或 `Cmd+V` 貼上剪貼簿圖片。多檔依檔名自然排序（`shot 1`、`shot 2`、`shot 10`）。
3. **畫面／字幕類型**：預設第一張是「畫面」、其餘是「字幕」。點圖上的徽章切換；每個「畫面」開啟新一幕。第一張一定是畫面。
4. **字幕列範圍（紅框）**：畫面圖上的紅框決定字幕列位置與大小，拖曳上緣與下緣調整（下緣上移可避開底部留白）。每一幕各自一組範圍：預設沿用前一幕；在某幕拖曳後即自訂，後續未自訂的幕跟隨該幕；調整第一幕會帶動所有未自訂的幕。把該畫面切成字幕再切回，即回到沿用。並記住最近一次調整的範圍。
5. **縮放檢視**：雙指縮放、`Cmd+=`、`Cmd+-`、`Cmd+0`（25%–400%）。縮放只影響畫面，不影響輸出。
6. **調整順序**：垂直拖曳項目，可跨幕移動；拖曳時有插入線，靠近上下緣會自動捲動。`Delete` 移除選取項目。
7. **完成**：按「完成」或 `Cmd+Return`，結果會複製到剪貼簿，可直接貼上；清單保留，可繼續調整後再複製。「清空」移除全部項目。
8. **輸出解析度倍率**：工具列可選 25%、50%、75%、100%（預設 100%）。Retina 截圖若太大可降為 50%。倍率不影響預覽。
9. **選擇性存檔（預設關閉）**：在選單列圖示上按右鍵，或點視窗工具列的齒輪設定，可勾選「同時存檔到資料夾」並選擇資料夾；開啟後每次「完成」會另存一份 PNG（檔名含時間戳）。
10. **視窗內設定（選單列隱藏時使用）**：排版視窗工具列右側的齒輪圖示，內含「同時存檔到資料夾」、「選擇存檔資料夾…」、「浮在所有視窗之上」、快捷鍵狀態（被佔用時顯示警示）與「離開」，效果與選單列右鍵選單相同、狀態同步。其他 App 全螢幕、選單列被隱藏時，仍可在視窗內完成所有設定。

## 標記模式

工具列的「排版／標記」切換。切到「標記」後，可直接在長圖上加標記，按「完成」時會一併烙進輸出（也會隨輸出倍率縮放）。

- **工具**：選取、文字框、矩形、箭頭、馬賽克。選工具後在長圖上拖曳出範圍（箭頭為起點到終點）；標記限制在長圖範圍內。建立後回到選取工具。
- **文字框**：建立後直接輸入文字，`Esc` 或點空白處提交；雙擊既有文字框可再編輯。
- **選取工具**：點選標記後可拖曳移動、拖把手縮放（箭頭為兩端點）、`Delete` 刪除。
- **樣式**：選取標記或選工具時出現樣式面板。文字框可設文字色、底色（含「無」）、字級、粗體、邊框；矩形與箭頭可設顏色與粗細。新建標記沿用上次選用的樣式，重啟後保留。
- **撤銷**：`Cmd+Z` 撤銷最近一次標記操作（新增、移動、縮放、改樣式、刪除）；沒有可撤銷時無作用。
- 標記模式下停用拖曳排序、紅框把手與徽章點擊；縮放檢視仍可用。切回「排版」後標記保留並繼續顯示（唯讀）。「清空」會一併移除全部標記。

## 輸出規則

- 項目由上而下緊貼堆疊（包含幕與幕之間），底色為黑色。
- 輸出寬度以第一張為基準；寬度不同的圖會等比縮放到同寬。

## 已知限制

- 紅框以「幕」為單位，不能每張字幕圖各自設定；各幕紅框高度不同會使長圖高度改變，標記位置相對內容偏移，請先排好版再標記。
- 標記附著在長圖上：之後重新排序項目或調整紅框，標記不會跟著內容移動，建議先排好版再標記。
- 馬賽克只是區塊化遮蔽，不是加密，不應視為安全遮蔽（敏感資訊請確認輸出結果）。
- 受 DRM 保護的內容，截圖本身可能是黑畫面，這是系統限制。
- 只有 ad-hoc 簽署，沒有 App 圖示，也未沙盒化。
- 快捷鍵固定為 `⌃⌥Space`，無法自訂；若被其他 App 佔用，選單最上方會顯示警示，仍可點選單列圖示開關視窗。
